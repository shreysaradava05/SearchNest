# SearchNest

A simple search engine page made with only **HTML and CSS** (college project).

## Features
- Search with Google, DuckDuckGo or Bing
- Quick links to popular websites
- About page
- Mobile friendly
- SEO meta tags

## Folder Structure
```
SearchNest/
├── index.html      (home page)
├── about.html      (about page)
├── css/
│   └── style.css   (all styling)
└── README.md
```

## How to Run
Open `index.html` in any browser. No installation needed.

## Technologies
HTML5, CSS3
